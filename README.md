# AromaCraft Studio｜手作精油配方與成本管理系統

以 Google Apps Script Web App 與 Google Sheets 保存家庭共用資料，定位為精油分享會的材料與包材成本估算。桌機兩欄工作台（配方與成本合併、原料加寬）、平板上下配置、手機單欄與底部摘要；價格在設定頁維護。新版尚未更新至正式 Google 部署，配置及驗證界線見 [桌機與手機配置](docs/桌機與手機配置.md)。

## 線上使用

[開啟 AromaCraft Studio](https://lianghao02.github.io/AromaCraft-Studio/)：資料保存在目前瀏覽器，不同步 Google 或其他裝置。換電腦前請在「資料與維護」匯出備份。也可直接開啟下載包的 index.html。

## 開始使用

1. 正式使用：依 [安裝部署說明](docs/安裝部署.md) 建立試算表、貼上 `src/` 原始碼、設定家庭 Google 帳號白名單並部署。
2. 部署前試用：安裝 Node.js 20 以上，於專案資料夾執行 `npm run preview`，開啟 `http://127.0.0.1:8765/`。無須安裝套件。按 Ctrl+C 結束。
3. 驗證：執行 `npm test` 與 `npm run check`。測試使用記憶體中的 Google 服務替身，不接觸真實帳號或試算表。

**本機預覽不會寫入 Google Sheets**。示範資料僅存於啟動程序的記憶體，重新啟動即重設；草稿以分頁暫存區隔離。正式 Web App 則依帳號保存瀏覽器本機草稿。

## 已完成功能

- 按摩油、無水精油膏、融製精油皂、日常清潔液、水垢清潔五種空白作品範本；用量與做法需人工確認。
- 原料新增、編輯、停用、分類、搜尋；不刪除既有價格與配方關聯。
- 自由加入及移除原料，編輯 g、mL、整數滴數與固定總量 %；可指定基底補足，缺少換算資料時拒絕猜測。
- 批次重量等比例換算、合格產量、每件重量。
- 配方新增、複製、讀取指定版本、每次修改另存新版本；舊版本衝突檢查。
- 採購價格批次、會員／優惠價文字標籤、g／kg／mL／瓶／包／盒重量換算。
- 主頁即時計算材料＋包材的本次總成本及每份成本；事前設定包材預設，不要求填人工、工時、毛利或售價。
- 安全來源與登錄規則提示；沒有可靠資料時顯示「待驗證」，超出已核對規則時顯示「超出限制」。
- 製作日期、實際合格產量、配方版本及成本快照；更新價格或原料品名不改變已儲存快照。
- 配方搜尋、產品篩選、依版本建立時間排序；JSON 備份匯出，試算表副本備份流程。
- 每個資料 API 的 Google 帳號檢查、伺服器重新計算、鎖定與版本衝突防護、寫入失敗保留草稿。

## 使用流程

手機收納版已於本機完成：進階功能按需展開，已存配方先顯示最新版，空白與未修改版本避免重複儲存。更新 Google 部署需替換三個前端檔，詳見 [介面更新步驟與驗證限制](docs/介面更新.md)。

選作品或直接挑原料 → 點配方卡填用量 → 看大約成本 → 儲存版本。單價及包材事前在設定頁準備。

新增原料後，請按「新價格」新增採購批次。要採用新批次，必須在配方卡片中選取；系統不會自動替換舊配方的價格。若沒有採購批次，該配方不能保存。範本附零元示範價格，正式計算前須改選實際價格。

指定「重量補足原料」後，調整其他原料會扣除或補回指定原料，使總重不變。比例編輯需要另一張補足原料卡；補足重量不足時會拒絕操作。未指定補足原料時，可自由改 g，總重隨之變動。

儲存已載入的最新版本會新增 v2、v3 等版本；載入舊版本後若已有新版，必須先複製成新配方或重新載入最新版本。製作紀錄只接受已儲存且沒有未儲存修改的版本。

## 計算定義

- 材料成本：各項換算後用量 × 所選價格批次的每 g 或每 mL 單價。
- 包材成本：每份包材費 × 本次份數。
- 本次總成本：材料成本＋包材成本；每份成本為總成本 ÷ 份數。
- 現場版本不加入人工、工時、毛利與售價。舊快照保留原紀錄。
- 計算保留完整精度，畫面金額四捨五入到小數點後 2 位。比例顯示的個別四捨五入可能使視覺合計有微小差異。

## 精油比例（v1.3.0）

新作品按類型帶入重量或容量基準，原料區與確認區同步顯示比例；重量配方的 mL／滴數原料可補本次實秤重量，不改採購單位，也不重複計費。缺資料會指出原料並顯示可用添加量；比例不代表兒童適用性。詳見 [精油比例與單位引導規格](docs/精油比例與單位引導規格.md)。

精油滴數於 v1.3.1 起，未有個別設定時預設採 **20 滴／mL 估算**，不需逐項填寫；已有換算值優先沿用。滴數只能換成容量，不能替代重量資料。

## 自製配方與製作類別（本機修訂）

選製作類別 → 加入原料與用量 → 確認比例、成本與份數 → 儲存。類別為精油膏、清潔劑、精油皂、按摩油、其他，不預填材料或做法。配方庫依相同類別分組與篩選；舊類型僅映射顯示，不改寫歷史資料。精油膏與精油皂預設重量基準，其餘容量基準；不是冷製皂皂化計算或安全適用性判定。此流程已併入正式版本。

多選原料修訂：第2步點卡片勾選／取消，可跨搜尋與分類挑選；按「填寫用量」後依序填每項，套用後自動到下一項，最後進入第3步。已套用的用量在中途關閉時保留。第2步不重複顯示完整比例，第3步聚焦比例與成本，逐項用量預設收合。

## 基底油容量與舊資料（v1.4.2）
新建基底油試算資料預設100 mL；舊g採購資料仍保留。在基底油用量視窗按「修改採購單位與價格」，填實際瓶裝容量／單位／價格，儲存後返回原連續用量流程。非零重量不直接當作容量，必須重新輸入mL並套用；關閉視窗保留原用量。歷史價格批次與成本快照不改寫。
精油以20滴／mL作估算，個別有效換算仍優先；基底油使用容量，不套用精油滴數。容量估算濃度＝精油容量÷全部原料總容量×100%，包含精油本身；g與mL混用仍需一致換算資料或實秤重量。引用文章的20滴說明針對精油：https://www.japanaceshop.com/blog/posts/carrier-oil 。未將族群稀釋參考表當作自動安全通過條件。

## UI／UX 調配流程修訂（v1.5.0）

### 單位與濃度（v1.5.2）

製作時新增精油預設使用滴；更改單位保留輸入數字，例如1 mL改選滴會成為1滴。容量換算留在成本與濃度計算內部，預設20滴／mL估算，已有個別設定時優先使用。按確認時重新讀取各項畫面用量；錯誤會指出原料及原因，修正後立即消失。原料類別不再阻擋已有完整容量資料的濃度：精油膏若全部可換算mL，就顯示容量估算百分比。30 mL基底＋6滴精油＝約0.99%；100 g基底＋6滴且缺重量換算時，只顯示每100 g基底6滴，不能冒充濃度百分比。
