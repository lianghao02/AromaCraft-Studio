# AromaCraft Studio｜手作精油配方與成本管理系統

> 🌐 **線上免安裝直接使用**：[https://lianghao02.github.io/AromaCraft-Studio/](https://lianghao02.github.io/AromaCraft-Studio/)  
> 💻 **本機離線免伺服器**：直接在瀏覽器雙擊開啟根目錄之 `index.html` 即可開箱即用，資料自動儲存於瀏覽器 LocalStorage。

支援 Google Apps Script Web App 雲端同步與純前端本機離線雙模式。原始碼採配方調製／成本利潤雙模式；手機原料卡兩欄、配方卡單欄，桌機以雙欄工作檯呈現。

## 開始使用

1. **直接開啟網頁**：
   - 線上版：造訪 [GitHub Pages 線上站點](https://lianghao02.github.io/AromaCraft-Studio/) 即可直接調配方、算成本與管理原料。
   - 本機版：直接用任何瀏覽器（Chrome, Edge, Safari, Firefox）開啟本專案根目錄的 `index.html`。
2. **正式 Google 試算表同步**：依 [安裝部署說明](docs/安裝部署.md) 建立試算表、貼上 `src/` 原始碼、設定家庭 Google 帳號白名單並部署為 Web App。
3. **驗證與建置**：執行 `npm test`（19 項測試通過）與 `npm run build`（自動編譯最新單一靜態網頁 `index.html`）。

## 使用流程

手機收納版已於本機完成：進階功能按需展開，已存配方先顯示最新版，空白與未修改版本避免重複儲存。更新 Google 部署需替換三個前端檔，詳見 [介面更新步驟與驗證限制](docs/介面更新.md)。

選作品 → 選原料卡 → 點配方卡調整重量／價格 → 設定產量與成本 → 儲存版本 → 記錄實際製作。

新增原料後，請按「新價格」新增採購批次。要採用新批次，必須在配方卡片中選取；系統不會自動替換舊配方的價格。若沒有採購批次，該配方不能保存。範本附零元示範價格，正式計算前須改選實際價格。

指定「重量補足原料」後，調整其他原料會扣除或補回指定原料，使總重不變。比例編輯需要另一張補足原料卡；補足重量不足時會拒絕操作。未指定補足原料時，可自由改 g，總重隨之變動。

儲存已載入的最新版本會新增 v2、v3 等版本；載入舊版本後若已有新版，必須先複製成新配方或重新載入最新版本。製作紀錄只接受已儲存且沒有未儲存修改的版本。

## 計算定義

- 原料成本：各項重量 × 所選價格批次的每克成本。
- 耗損成本：原料成本 ÷（1 − 耗損率）− 原料成本。配方 g 為所需淨用量；若填入的是實際投入量且產量已含耗損，請將耗損率設為 0，避免重複計算。
- 包材：每件包材費 × 合格成品件數；工時：批次分鐘 ÷ 60 × 時薪。
- 每件成本：（原料＋耗損＋包材＋工時＋其他）÷ 合格成品數量。
- 建議售價：每件成本 ÷（1 − 目標毛利率）；實際毛利率：（自訂售價 − 每件成本）÷ 自訂售價。
- 計算保留完整精度，畫面金額四捨五入到小數點後 2 位。比例顯示的個別四捨五入可能使視覺合計有微小差異。

目前交付可部署原始碼與已驗證的本機第一版。2026-10-11 已在使用者連接的 Google Drive 建立真實八表資料庫，讀回確認欄位、示範資料與 Asia/Taipei 時區；權限僅擁有者，沒有公開共享。**使用者已建立 Apps Script 與正式網址；配方 v1、v2、v3 的雲端寫入已讀回確認。家庭跨帳號與本次新版 UI 尚未實測**。所有家庭帳號需授權並擁有資料試算表編輯權限。程式採拒絕存取的預設：帳號身分空白、不在白名單或執行身分不符即停止。私人部署資料保存在版本庫以外，不將帳號或試算表 ID 寫入 Git。

家人具有直接編輯試算表的能力，請只加入可信任成員；應用程式的快照不變保證不涵蓋人為直接修改工作表。建議使用獨立 Apps Script 專案，只讓維護者具有程式編輯權限。不同 Workspace 管理政策或個人帳號的部署選項可能不同；不能取得可靠身分時，必須停用家庭共用部署，維持僅本人存取，不能改成匿名或只靠前端隱藏。

不含冷製皂皂化計算、庫存、訂單、金流、公開註冊、採購優惠自動抓取、安全適用性判定、定時備份或 JSON 自動匯入。單份配方最多 200 種原料，單格快照限制 45,000 字元；家庭少量資料以整表讀取，未針對大量商業資料最佳化。
