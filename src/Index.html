編輯

AromaCraft 使用說明

🌿 三步驟完成配方試算

  1. 選製作類別：點一個類別，會直接進入下一步；儲存後可在配方庫依類別查找。
  2. 選原料與填用量：點原料加入，直接在「已選原料」那一列填用量與單位。底部會顯示已選項數與精油濃度，填完按「下一步」；換算不足時會提示補資料。
  3. 看成本並儲存：先在設定頁準備材料價格與包材費，現場只調用量、看成本、儲存。請核對材料、用量與做法。製作紀錄在配方庫下方。

⚖️ 單位與數值換算原則

  • 比例 %：全部以 g 或全部以 mL 計量時可設定總量及比例。混合單位會依原料密度換算濃度；資料不足時仍可保存配方。
  • 容量與滴數：設定頁填一罐或一份的容量（g／mL）與價格。精油預設以每 mL 20 滴估算；已有個別換算值時優先沿用，可在原料設定自訂。
  • 配方與製作紀錄分開：更新配方採最新價格試算；完成製作才保存當次實際用量與成本，日後改價不影響紀錄。

☁️ 家庭資料與離線草稿

GitHub 網頁版登入後由 Firebase 保存家庭資料；Apps Script 版仍使用原有 Google 試算表。每次編輯皆會於瀏覽器保留本機草稿，重新整理或意外斷線皆可隨時復原。
