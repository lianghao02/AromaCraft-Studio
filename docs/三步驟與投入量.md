# 三步驟與投入量（v1.2.1）

1. 選作品範本或從配方庫載入既有配方。
2. 點原料卡填使用量；已選原料集中顯示，可修改或移除。單位預設跟隨採購單位，同類 kg/g、L/mL 可換算，無有效密度不提供重量／容量互換。精油每 mL 幾滴可在本次用量或原料的選填換算設定填寫，沒有通用預設。
3. 修改配方名稱及本次份數，確認材料成本、包材、本次總成本及每份成本。原料明細唯讀，要調整請返回第 2 步。可直接儲存配方或以本次日期保存製作紀錄，沿用用量、份數及成本快照。

投入量分別合計 g、mL，另列精油滴數；已換算的滴數包含於對應的容量合計，不能重複加總。未量測產出時只稱配方投入量。份數為正整數，只改分攤與按份計費包材，不改整批材料用量。

採購單價＝價格／數量，先把使用量換成採購同類單位再估成本。明確填 0 元視為零成本；空白價格、沒有價格批次或缺換算資料時，列出原料與待補原因，顯示已知材料費，完整總計及每份成本標示未完整。缺價可從確認區直接補價格，換算不足請返回第 2 步或原料設定。

精油比例自動判斷同一基準：全部可用 g 計算時標重量百分比；全部可用 mL 計算時標容量估算百分比。不能混加重量與容量產生百分比。基底可用 g、精油以滴輸入且無重量換算時，顯示每 100 g 基底的滴數添加比例，不稱濃度。只有實際滴數項目納入此添加比例；其他未換成滴的精油仍保留自己的用量。

參考上限藏在展開區，使用者需指定 g 或 mL 基準。只在相同基準時比較，不阻擋其餘成本統計，也不判定適用性。歷史成品容量、固定總量、補足原料設定保存在濃度設定的 legacySizing／totalMl，不清除歷史快照；新版確認流程按實際用量運作。
