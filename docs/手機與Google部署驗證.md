# 手機與 Google 部署驗證

確認日期：2026-10-13；應用版本 v1.2.2。

## 已完成
- 使用者提供 iPhone 操作截圖：用量 1.5 可輸入，顯示含小數點鍵盤；「手機驗證」v1 已出現在配方庫。這是本機保存證據，不代表 Firebase 已同步。
- 官方 Apps Script 編輯器已更新七個程式檔，原資訊清單的 USER_ACCESSING／MYSELF 保留。先備份原六檔，執行 migrateUnitSchema 完畢，再更新原部署至第 5 版；原網址不變。
- 正式網址讀回 v1.2.2 與既有配方 v6、歷史版本。Google 版本隱藏 Firebase 登入面板，標示資料保存於 Google 試算表。兩平台資料仍各自獨立，未搬移或清空。
- 修正 iPhone 截圖中日期原生欄位向右溢出的樣式；滴數換算及採購數量增加 decimal 輸入模式。
- 53 項既有測試通過，語法與部署引用檢查通過。

## 未驗證
- 最新日期樣式與滴數鍵盤修正尚需 iPhone 重新整理後回測；Windows 瀏覽器尺寸模擬不能取代 Safari。
- 使用者截圖未顯示瀏覽器網址，無法將該次操作視為 Google 部署或 Firebase 家庭同步驗收。
- 手機返回調整後的資料保留、份數 2 的分攤與重新開啟保存資料，仍需使用者完整回報。
- 自動截圖介面不可用，Google 部署成功以官方管理部署訊息與正式頁面讀回確認。

## 回測步驟
用 iPhone Safari 重新整理使用中的網站，測試輸入 1.5、滴數換算欄位的鍵盤、套用、修改份數為 2、日期欄位、返回第 2 步修改與保存讀回。原資料不要清除。
