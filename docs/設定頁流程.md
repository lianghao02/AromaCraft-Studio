# 設定頁流程

## 原料與包材（預設入口）

原料庫固定在這裡，點卡片直接編輯名稱、容量與價格；不會加入配方。桌機左原料、右包材，手機先原料後包材。回調配方後，原料庫恢復選取用途與先前收合狀態。

## 製作紀錄

先在調配方儲存，再於此填日期、份數及製作備註。切換設定用途不會清掉輸入。安全來源可另外展開查看。

## 資料與維護

連線、草稿及備份在此查看；首次安裝與更新工具預設收合，平常製作不用操作。獨立官網目錄及示範測試按鈕也放在此處。

40 項程式測試與語法檢查通過，涵蓋設定導航及編輯用途；瀏覽器工具無可操作表面，排版實測仍待完成。沒有修改後端、Google 資料或原計算規則。本機 18767 重新整理即可使用。
