# 手機介面收納更新

主流程保留選作品、配方卡、名稱與產量；底部固定成本、安全狀態與單一儲存按鈕。選作品後自動收合並移至配方，加入原料時展開原料庫。

重量換算、補足原料、備註與複製收在更多配方設定。原料管理與新價格收在卡片內。成本、安全詳細資訊、已存配方、製作紀錄及資料備份各自展開。安全摘要仍固定可見，不將待驗證誤標為安全通過。

每份已存配方先顯示最新版，舊版收在歷史版本。顯示未儲存狀態；空白及沒有修改的已存版本不能重複按儲存，編輯或複製後恢復可存。收合不清除草稿。

## 更新到 Google Apps Script

1. 開啟專案 `src/Index.html`、`src/Styles.html`、`src/Client.html`。
2. 將完整內容貼入 Apps Script 的同名檔案並儲存；本次只需更新這三個檔案。
3. 部署 → 管理部署 → 選現有部署 → 編輯 → 版本選新增版本 → 部署。
4. 使用原有 `/exec` 網址重新整理。編輯器儲存不會自動更新正式版本。
5. 沿用資料表及指令碼屬性，不重建或清空資料庫。

## 驗證界線

原有 18 項核心及服務測試通過。新增用戶端 DOM 替身測試，確認空白防誤存、選作品收合、展開原料庫保留草稿、儲存中及已存狀態、失敗重試、歷史版本載入與複製。

瀏覽器工具仍回報沒有可用瀏覽器；尚未實測本次新版的版面、觸控、鍵盤與 Safari，未代為更新雲端部署。

部署後請確認：390 px 手機寬度無橫向捲動；收合再展開保留草稿；加入原料能編輯；儲存新版並讀回；既有歷史版本能載入；底部編輯面板的按鈕可見。


## 成本與操作訊息補強

費用逐欄標示 NT$／件、分鐘、NT$／小時及整批 NT$，並說明整批與每件的分攤。結果分列整批成本、每件成本、建議售價、預計售價、預估毛利與毛利率。零元採購批次提示可能低估；預估毛利只扣除已填費用，不等同淨利。家庭預設儲存另行收納並說明適用於下次新配方。

切換作品、載入歷史版本與恢復草稿，改用站內確認對話框，顯示目前配方及目的配方，按鈕為返回繼續編輯／放棄修改並切換。Esc 與返回均保留目前修改。關閉或重新整理整個分頁的未儲存提示仍由瀏覽器管理。

19 項測試與語法檢查通過；用戶端測試新增確認取消保留草稿、同意才切換及零元價格提示。公式未變更；本次尚未由瀏覽器工具操作正式頁面。更新仍只需完整替換三個前端檔，再新增部署版本。
