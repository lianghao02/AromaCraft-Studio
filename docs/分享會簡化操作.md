# 分享會簡化操作

## 原料與價格

設定頁點原料的管理按鈕，填商品名稱、原料類別、一罐／一份容量、g 或 mL、一罐／一份價格。一次按儲存即可；不要求採購批次、密度或滴數。

系統在內部保留價格紀錄，使已儲存配方的歷史成本不被新價格覆寫。新加入材料使用最新設定價格，已存配方沿用其保存價格。

## 製作用量

新配方預設 g／mL 分開計量，各項用量按自己的容量單位估成本。混合單位不硬湊總重量或總濃度，例如 100 g 皂基與 0.5 mL 精油分開列示，材料費可以合計。

選「滴」時才填這瓶精油每 1 mL 約幾滴，依實測或已知資料填寫；未填就改用 mL。沒有固定 20 滴等預設值，換算設定屬於這次製作，隨配方版本保存。

需要使用 % 時，改選「全部以 g」或「全部以 mL」計量，並在「製作備註與工具」設定總量。跨 g／mL 缺乏換算資料仍會拒絕，不以密度 1 猜測。

人工確認勾選已移除。平常僅需要材料、用量與份數，備註、列印、複製及清空按需要開啟。

## 配方庫

「編輯」載入配方，儲存後建立新版本。「移除」只收進已移除清單，可勾選「顯示已移除配方」後按恢復；歷史版本和製作紀錄都保留。

## 更新與驗證界線

正式 Apps Script 更新全套 src 檔後，管理員須再次執行升級單位欄位，追加配方明細的第 8 欄 dropsPerMl。不重建八表、不修改舊明細。舊格式照常讀取。

40 項程式與 DOM 替身測試、語法檢查通過；瀏覽器與真實 Google 仍待驗收。新增後端 API，需要重新啟動本機預覽，單純重新整理舊服務不足。本機示範和正式家庭資料分開。
