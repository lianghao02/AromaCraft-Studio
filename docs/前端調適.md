# 前端先完成，再接雲端

目前階段只調適前端，使用本機示範資料。既有正式 Apps Script 與 Google Sheets 保留，不需要每次修改畫面就重新部署。

## 預覽方式

1. 電腦需有 Node.js 20 以上，不需安裝任何套件。
2. 解壓縮前端預覽包，開啟「啟動預覽.cmd」。
3. 在瀏覽器開啟 http://127.0.0.1:8765/。
4. 預覽包的「前端預覽.html」已合併畫面、樣式與操作程式，可編輯後重新整理。專案開發仍由 src 分檔維護，再產生合併檔；合併檔修改若要正式採用，需回寫 src，避免兩份來源不同步。

不能直接雙擊 HTML 完成儲存操作：配方、版本與價格的示範儲存需要本機預覽服務。此 HTML 是前端預覽交付檔，不是可直接貼進 Apps Script 的部署檔。

## 調適順序與驗收

1. **入口與順序**：先決定新增／載入配方的入口，再安排選作品、加入原料、編輯配方、試算與儲存。管理功能放次要區域。目前入口重排尚未完成。
2. **手機操作**：以 390 px 直向檢查文字、44 px 觸控範圍、底部面板及固定成本列；確認最後一個欄位不被遮住。
3. **成本與訊息**：核對整批／每件、單位、毛利算法與零元批次提示；取消切換保留輸入，儲存失敗可以重試。
4. **完整流程**：選作品、加入／移除原料、調整重量、儲存、載入與複製；歷史版本與快照保持不變。
5. **接回雲端**：前端流程定案後產生部署檔，一次更新正式版本，再驗收 Google 授權、真實資料讀寫與手機 Safari。

本機示範資料只存在啟動程序的記憶體，重新啟動會重設；不會寫入 Google Sheets，不是正式資料備份。仍需真實瀏覽器與手機實測，不能只以自動測試認定 UI／UX 已完成。
