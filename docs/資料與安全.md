# 資料結構與安全邊界

## 八張繁體中文工作表

工作表名稱使用繁體中文，欄位鍵保留固定英文程式識別碼；不以原料名稱建立關聯。表頭為資料庫介面，不得翻譯、更名、插入或刪除欄位。可於 Google 試算表使用欄位註解保存中文說明。

| 工作表 | 固定欄位（依順序） | 用途 |
|---|---|---|
| 原料資料 | id, name, category, active, note, revision | 原料 ID、名稱、分類、啟用、備註、修訂版本 |
| 原料價格 | id, materialId, label, amount, unit, paid, density, gramsPerUnit, createdAt, createdBy | 批次 ID、原料 ID、批次標籤、採購數量／單位／總價、密度、每單位 g、建立時間／帳號 |
| 配方資料 | id, version, name, type, units, notes, baseId, costJson, snapshotJson, requestId, createdAt, createdBy | 配方 ID／版號、名稱、類型、合格件數、說明、補足原料、成本設定／計算快照、請求 ID、時間／帳號 |
| 配方明細 | recipeId, version, materialId, grams, priceId | 配方 ID／版號、原料 ID、g、採購價格批次 ID |
| 安全規則 | id, materialId, type, maxPercent, source, status, note | 規則 ID、原料 ID（`*` 為精油合計）、產品類型、上限%、來源、核對狀態、適用條件備註 |
| 製作紀錄 | id, recipeId, version, date, units, notes, snapshotJson, requestId, createdAt, createdBy | 紀錄 ID、配方 ID／版本、臺灣製作日期、實際合格件數、備註、成本快照、請求 ID、時間／帳號 |
| 成本設定 | id, valueJson, createdAt, createdBy | 家庭預設設定的不可覆寫修訂；最後一列為現行預設 |
| 系統設定 | key, value | 資料庫版本、系統名稱；帳號白名單不放在此表 |

分類支援精油、皂基、蜂蠟、基底油、其他。作品類型固定為「融製精油皂」「無水精油膏」。價格 `unit` 支援 g、kg、mL 及有每單位 g 的其他文字單位。

## 安全規則維護

初始 `安全規則` 沒有任何限制數字。只有取得可核對、適用於特定原料及產品類型的資料後，維護者才應登錄 `maxPercent`、`source`、適用範圍與備註，將 `status` 設為「已核對」。其他狀態或缺來源、無效上限，皆不作為已驗證限制。

來源建議保留文件名稱、版本、頁碼、網址、取得日期與適用條件。程式僅比對已登錄資料，不自動驗證來源真偽與適用性。`materialId = *` 表示「這種產品的精油合計百分比」，不是涵蓋所有原料或所有使用者的安全保證。

規則判定以重量百分比為準。安全規則判定不使用估算密度（濃度顯示可用估算密度，並標示「估算」），系統不內建通用安全濃度、不處理孕婦、嬰幼兒、疾病、過敏、藥物、光敏性、皮膚用途或保存期限等完整評估；沒有足夠資料時保持「待驗證」。即使個別規則未超標，也不顯示「安全通過」。測試中使用的上限與比例全是合成數值，不能作為製作建議。

## 歷史快照與一致性

價格批次、新配方版本、成本設定修訂與製作紀錄皆追加，不覆寫。配方快照保存當時計算的原料名稱、類別、重量、比例、批次標籤、每克價格、各項成本、售價設定及安全訊息；製作紀錄複製指定版本快照，再依實際合格產量分攤每件成本與包材。

載入配方編輯時採用原配方批次價格，並依目前原料資料與安全規則重算；重新命名或安全規則變更可能改變畫面提示。舊版快照與既有製作紀錄保持不變，舊安全快照不能當作現時安全審查結果。

所有 API 採 Script Lock。配方明細先寫入，再寫配方資料作為提交標記，讀取端不呈現未提交版本；若標記寫入前失敗，下次同版本重試清除孤兒明細後重新寫入。這不是 Google Sheets 的完整多表交易，只針對這條寫入流程提供恢復能力。人工修改／排序／刪除與外部腳本不受同一把鎖控制。

配方、價格、製作紀錄採請求 ID 去除重複；同一未改動草稿重試保持 ID。版本與原料修訂採樂觀衝突檢查。若寫入成功但回應遺失，重新讀取確認後再操作；重新整理頁面或修改草稿會影響重試狀態。

## 存取與輸入防護

每次 API 重新取得 Google Active／Effective User，拒絕空身分、兩者不符及白名單以外帳號；不接受瀏覽器提供的 Email 作為授權依據。管理員身份僅用於初始化，成本與配方管理開放白名單成員使用。

伺服器會再驗證數值、型別、價格關聯、產量與配方版本，成本不信任用戶端送來的快照。名稱、備註與來源以文字顯示並做 HTML 跳脫；寫到 Sheets 的公式開頭文字轉為字面值。內部函式以底線結尾，不能從 `google.script.run` 直接呼叫。

所有家庭成員必須有試算表編輯權限，所以仍可直接修改工作表。此架構適合互相信任的家庭成員，不是對惡意家庭帳號的多租戶隔離系統。撤銷成員時必須同時移除 Script Properties 白名單與試算表共享權限；已匯出或已讀取的資料不能遠端收回。

不提供公開註冊、匿名 API、權杖登入、密碼儲存。真實部署、授權與跨帳號驗收依安裝部署說明執行。
