# 桌機與手機配置

本次沿用現有米白、綠色卡片，針對精油分享會的「選原料、填用量、看成本」配置。

| 畫面寬度 | 配置 |
| --- | --- |
| 1100 px 以上 | 三欄工作台：左挑原料、中編配方、右看成本及儲存。原料清單獨立捲動。 |
| 768–1099 px | 配方與成本兩欄，原料按需展開。 |
| 767 px 以下 | 單欄配方，按「加入原料」展開選擇；底部常駐成本摘要及儲存。 |

## 主流程

1. 可直接挑原料，或展開作品範本選擇作品。
2. 點配方原料卡，填 g、mL 或已設定換算資料的滴數。
3. 看本次總成本與每份成本，儲存配方。

主畫面保留名稱、份數及合計單位。固定總量、補足、等比例縮放、製作說明、人工確認與列印放在「進階用量與製作備註」。使用 % 時，先在該區勾選指定總量並填數值。密度與滴數規則仍依價格批次，不猜測。

精油先按「單方／複方」篩選，未能對應官網分類的自建原料顯示「待分類」。卡面以簡短名稱、容量與整瓶批發價呈現，例如「乳香｜15 mL · 批發價 NT$3,180」。實際採購批次標「採購價」，不冒稱官網批發。原名稱、查價時間與批次明細仍保存，成本計算繼續使用每 mL／g 單價。

價格與包材在「設定與資料」預先維護；現場不填工時、毛利或售價。獨立官網目錄試算也移至設定區，現場直接使用主原料庫，避免兩套試算混淆。
