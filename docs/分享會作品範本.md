# 分享會作品範本更新

新增按摩油、無水精油膏、融製精油皂、日常清潔液、水垢清潔五種作品。範本只提示材料結構，點選後建立空白配方，沒有預填任何比例、濃度或混合指引。

## 現場操作

選作品 → 加入太太確認的材料與用量 → 查看材料＋包材大約成本 → 儲存。主頁取消成本利潤模式，不輸入人工、工時、毛利或售價。原料管理及包材預設從「設定與資料」進入。新範本採用家庭包材預設；修改預設不改目前草稿或歷史版本。

材料單價與零元示範價未核對時顯示估算不完整，不將零元示範當作免費材料。現有配方仍以 g 計算，官網 mL 精油目錄維持獨立試算，尚未併入重量配方。

## 確認狀態

「太太已確認材料、用量與做法」是人工標記，儲存在配方備註的 [太太常用] 標籤，未確認使用 [範本待確認]。配方庫會顯示狀態；修改內容後自動回到待確認。此標記不代表安全審查通過，安全提示仍保留待驗證。空白配方不能儲存。

清潔與去水垢是不同作品，不提供混合化學品比例，也不宣稱精油可以消毒或去除水垢。融製皂不支援冷製皂皂化。

## 相容及部署

Google Sheets 八表與歷史快照結構不變；後端接受三種新增作品類型。舊版本快照保持原值；主頁試算只看材料與包材，修改後另存的新版本排除人工、耗損、其他費用與定價。舊版完整成本仍保存在原歷史快照中。

GAS 須更新 Code.gs、Core.html、Index.html、Styles.html、Client.html，並保留前輪 Catalog.html。現階段只交付本機前端，尚未更新正式部署。
