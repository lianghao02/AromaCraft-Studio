# 精油體積濃度

在「確認配方與成本」上方填寫本次整批成品容量（包含精油）及可選的目標濃度上限。沒有指定容量時，只有全部原料都能換成 mL 才自動合計；g 不直接當成 mL。

濃度 = 各瓶精油換成 mL 後的合計 ÷ 成品總容量 × 100%。每瓶滴數換算依本次製作資料，不使用統一預設滴數。沒有容量或精油換算資料時顯示待確認。

有目標上限及成品容量時，用量視窗顯示所選瓶最多滴數與尚可增加滴數，扣除其他精油的體積後向下取整。這是該瓶的可用滴數，不是所有瓶子的共同上限。

超過自訂目標時拒絕套用及保存。可換算的全部原料合計與手填成品容量不同時，可繼續編輯，但不可保存；重量材料無體積資料時，使用手填容量的體積估算。皂、膏只知道重量可留空，不顯示假濃度。

濃度或自訂上限不判定兒童可用，仍需核對年齡、各成分及用途。此功能沒有提供建議安全濃度。

Apps Script：更新八份原始檔後，在設定頁再次執行「升級單位欄位」，為配方資料追加 concentrationJson；舊配方可繼續讀取，歷史濃度設定與計算快照保留。
