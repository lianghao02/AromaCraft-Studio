# 悠樂芳分類目錄

以分類切換＋搜尋＋每批 24 張等高卡片顯示，不使用全部品項瀑布流。預設單方精油，分類包括配方精油、滾珠、按摩油及套裝。商品名與編號可搜尋，切換分類或搜尋會重設為前 24 張；需要時按「再顯示 24 筆」。庫存及官網連結收在卡片詳情。

原料庫內展開「悠樂芳精油目錄與成本試算」即可使用。點卡片加入獨立精油試算，再填 mL 用量，不預填製作用量。以官網批發價÷容量估算，每項未填用量時顯示待填提示；移除與清空只影響本次精油試算。

## 資料與邊界

112 筆官網規格＋42 筆沒有公開規格的商品索引，共 154 張目錄卡。預設只顯示 102 筆容量與價格完整的資料；勾選待補品項才顯示其餘卡片。套組及未知容量／價格不可加入成本試算，不以零元代替。

官網查價時間與商品網址逐筆保存；含稅未含運費。滾珠／按摩油與純精油分開分類，不視為同類替代品。此目錄不是實際採購紀錄，現價可不同。

本次精油試算只計算精油，不含基底或包材；尚未併入以 g 計算的配方，也未保存到 Google Sheets。重新整理會重設本次試算。密度與滴數沒有可靠資料，不能假設 mL=g 或固定每 mL 滴數。

## 維護與部署

單一資料來源是 data/young-living-tw.json；介面程式來源為 tools/catalog-runtime.js。執行 npm run build:catalog 產生 src/Catalog.html，再 npm test 與 npm run check。

既有 npm run preview 自動包含新目錄。Apps Script 更新時需新增 HTML 檔 Catalog，再更新 Index.html、Styles.html；既有檔案保留。尚未部署到正式 Google 環境。
