# 精油縮圖

主原料卡右上顯示悠樂芳官網瓶圖，桌機 44×54 px、手機 38×50 px。圖與商品編號對應，94 筆官網單方／複方規格均取得有效 image 回應；示範及自建品項不猜照片。

圖片採延後載入與固定占位。載入失敗顯示占位標示，不影響搜尋、卡片選取或成本。圖片不帶出頁面來源，沒有使用圖片作為安全資訊。

官網原素材採外部連結，沒有複製至公開版本庫；離線或圖片主機改版時可能無法顯示。圖片只供辨識，容量與價格以卡片文字為準。

更新目錄後執行 npm run build:catalog，使部署資料與前端一致。正式 Google 本輪未部署，瀏覽器視覺驗收以 HANDOFF 為準。
