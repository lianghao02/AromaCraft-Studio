# 官網價格更新

## 怎麼用（給使用者）
1. 開啟網站 →「設定與資料」→「資料與維護」→「首次安裝與資料更新」。
2. 按「更新官網價格：複製提示詞給 AI」，再按「複製提示詞」。
3. 貼到 Codex、Antigravity 或 Claude Code（需開在這個專案資料夾）。AI 會自己查官網、更新、測試、升版、推送並確認部署，完成後回報變動清單。
4. 之後開啟網頁時，管理者會自動新增新的價格批次，不需要再按任何按鈕。

## 運作方式
- 價格來源是內建快照 `data/young-living-tw.json`；網頁本身**不會**即時連線官網。
- 只能用 `node tools/refresh-catalog.cjs` 更新快照（`npm run refresh:catalog`），不手動編輯、不編造價格。
  - 預設只預覽（dry run），列出變動清單；加 `--write` 才寫入。
  - 逐筆查官網公開介面（資料中的 `api` 欄位），間隔 0.4 秒、逾時重試 3 次。
  - 只有批發價或容量改變才更換查價時間；庫存或零售價變動只更新內容。查價時間決定是否新增一批價格。
  - 停止條件：失敗超過 10%（結束碼 2）；單筆批發價變動超過 30%、容量變動、官網突然沒有價格，或一次變動超過 30 筆（結束碼 3）。這些情況不寫入，需人工確認後加 `--accept-anomalies`。
  - 沒有官網介面的品項（目前 42 筆「公開價格待補」）原樣保留。
- `node tools/bump-version.cjs`（`npm run bump`）一次更新 `package.json`、`sw.js` 快取名稱、`src/Index.html` 頁尾與 README 標題；CHANGELOG 另外手寫。
- 提示詞內嵌在 `src/Index.html`（`#catalogRefreshPrompt`）；`tests/prompt.test.cjs` 會檢查提示詞提到的指令、檔案與結束碼確實存在，避免與工具脫節。

## 價格如何進到 App
- 部署新快照後，管理者開啟網頁時 `catalogStatus`（唯讀）發現有未載入的項目，會自動執行一次 `importCatalog`，寫入家庭雲端。
- 價格批次只追加：舊批次保留，已儲存配方的成本快照不變；「用最新價格試算」的配方與列表會改用最新批次。

## 限制
- 沒有公開價格（需登入）的品項抓不到；套組不自動拆分成本。
- 這是對官網公開介面的低頻查詢；官網若改介面或限制，腳本會報錯並停止，不會寫入亂資料。
- Apps Script 獨立部署需另外更新 `Code.gs`（含 `catalogStatus`）。
